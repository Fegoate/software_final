========================================
        简易邮件客户端
========================================

【功能介绍】
1. 邮件接收 - 通过 IMAP 协议接收邮件
2. 邮件发送 - 通过 SMTP 协议发送邮件
3. 邮件转发 - 一键转发邮件给他人
4. 邮件管理 - 浏览、删除、搜索邮件

【支持的邮箱】
- QQ邮箱
- 163/126邮箱
- Gmail
- Outlook/Hotmail
- 自定义邮箱服务器

【运行方式】

方式一：直接运行 Python 脚本
  1. 确保已安装 Python 3.6+
  2. 安装依赖：pip install PyQt5
  3. 运行程序：python main.py

方式二：打包成 exe 后运行
  1. 双击运行 build.bat
  2. 等待打包完成
  3. 运行 dist\邮件客户端.exe

【使用说明】

1. 登录配置
   - 选择邮箱类型（QQ、163等）
   - 输入邮箱地址和授权码（非登录密码）
   - 点击"登录"

2. 邮箱授权码获取方法
   QQ邮箱：设置 → 账户 → POP3/IMAP服务 → 开启 → 生成授权码
   163邮箱：设置 → POP3/SMTP/IMAP → 开启 → 设置授权码
   Gmail：需要开启两步验证，然后创建应用专用密码

3. 发送邮件
   - 点击工具栏"写邮件"
   - 填写收件人、主题、内容
   - 点击"发送"

4. 转发邮件
   - 在列表中选择要转发的邮件
   - 点击工具栏"转发"
   - 填写转发目标邮箱
   - 点击"发送"

5. 删除邮件
   - 选择要删除的邮件
   - 点击工具栏"删除"
   - 确认删除

6. 搜索邮件
   - 在搜索框输入关键词
   - 按回车或点击"搜索"
   - 可搜索发件人、主题、内容

【注意事项】
1. 密码处使用的是"授权码"而非登录密码
2. 首次使用需要在邮箱设置中开启 IMAP/SMTP 服务
3. Gmail 用户需要使用"应用专用密码"
4. 账户配置会保存在用户目录下 .email_client/config.json
